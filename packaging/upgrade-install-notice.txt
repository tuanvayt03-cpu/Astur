ASTUR VI UPDATE 2.4.0.18 (EXPERIMENTAL PREVIEW)

This is a community preview of Astur's in-place Windows update, not an
official upstream stable release. The new fullscreen overlay mode passed
Windows source/CI tests, but direct desktop one-/two-monitor acceptance
for your specific monitor and app mix is STILL PENDING.

BEFORE INSTALLING
- STOP any running Astur process first. NEVER run two window managers.
- Do not evaluate this preview in an active trading/MT5 session. Test
  first with disposable apps in an isolated Windows session.
- This installer retains the original Astur AppId and installed path,
  replaces the installed executables and preserves user configuration.
- It is UNSIGNED. Check SHA256SUMS.txt and the GitHub source.
- Do not disable Windows Defender or SmartScreen to bypass warnings.
- The installer closes conflicting applications if asked; check prompts.

ROLLBACK SAFETY
Installer backs up the existing Astur.exe, astur-settings.exe, astur.conf
and navbar.conf (when present) BEFORE overwriting existing files.
First original backup (kept across upgrades):
%LOCALAPPDATA%\Astur\UpgradeBackup\before-vi-update-2.4.0.1
Immediately preceding installation:
%LOCALAPPDATA%\Astur\UpgradeBackup\before-vi-update-2.4.0.18
Backups are not overwritten on repeat installation. On rollback, exit
Astur, restore previous binaries/config from these folders, or reinstall
the previous GitHub preview installer 2.4.0.17.

NEW IN 2.4.0.18
- CS1 can stay full-screen behind independently managed foreground slots.
- CS2 fills the right half; CS3 fills the empty left half; CS4 enters
  the OTHER N-1 slot without replacing the currently focused slot.
- Older overlay occupants stay managed and taskbar-recoverable.
- 1/4 and 1/5 foreground widths, native maximized background (untouched),
  minimize/close lifecycle handling, same- and cross-monitor slot swap.
- Improved native/custom-titlebar drag admission and hidden-workspace
  foreground-slot admission.

VERIFICATION LIMITATIONS
GitHub Windows CI tested Rustfmt, Clippy with warnings denied, Rust tests,
release build, upgrade/backup/rollback and uninstall smoke in an isolated
Windows runner. Real Telegram taskbar, Zalo popup click-through, dragging
and exact CS1/CS2/CS3/CS4 behavior still need desktop E2E.
A CI PASS is NOT real desktop acceptance.
