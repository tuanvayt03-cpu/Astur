ASTUR VI UPDATE 2.4.0.16 (PREVIEW)

This installer UPDATES your existing Astur installation IN PLACE.
It is an experimental community fork, NOT an official stable upstream release.

BEFORE INSTALLING
- Quit the running Astur window manager. Do not run two managers together.
- The installer retains the original AppId and installation directory.
- Your existing settings and workspace configuration are preserved.
- When prompted, allow the current app to close. Auto-restart is disabled.
- The installer is UNSIGNED. Verify its SHA256 and source. Do not disable
  Windows Defender or SmartScreen to launch an untrusted executable.

ROLLBACK
Before touching the installed files, the installer saves the existing
Astur.exe, astur-settings.exe, astur.conf and navbar.conf (when available).
First original snapshot:
%LOCALAPPDATA%\Astur\UpgradeBackup\before-vi-update-2.4.0.1
Immediately previous installation:
%LOCALAPPDATA%\Astur\UpgradeBackup\before-vi-update-2.4.0.16
These snapshots are never overwritten on a repeat update.
To roll back: quit Astur, restore the saved binaries/config, or reinstall
the previously used installer. Keep the other manager stopped.

NEW IN 2.4.0.16
- A new window fills an empty visible slot first; if all visible slots are
  full, it uses the previously focused OTHER slot (layer N-1), keeping the
  active anchor in place. The older occupant stays managed, not minimized.
- Automatic slot replacement NO LONGER enables a manual Astur tab bar.
  The black title strip is shown only after explicit Alt+Shift+T and only
  when a column has at least two windows. A lone File Explorer shows none.
- Taskbar, Alt+Tab and Astur app-bar activation of an older parked occupant
  now triggers physical unpark/retiling, not only an internal focus flag.
  Astur-owned stale SW_HIDE can be recovered without overriding app hiding.
- Manual Tab ON/OFF is independent from the automatic slot stack, and
  toggling it clears the automatic presentation state.
- Minimizing a window retains its scrolling slot, and restoring a minimized
  window places it back in that slot. Tab clicks use consistent indexes.
- Retains flexible within/between-monitor Alt or title-bar dragging, native
  top-edge maximize, and prior Window Policy Engine/Zalo protections.

ACCEPTANCE LIMITATIONS
The code and installer are tested on isolated Windows CI. The real
1-monitor and 2-monitor desktop (including 1/2, 1/4 and 1/5 layouts,
native maximized/F11 windows, MT5 and Zalo popups) still requires
manual acceptance. A CI pass is not a claim that live UI is verified.
