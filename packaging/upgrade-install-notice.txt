ASTUR VI UPDATE 2.4.0.13 (PREVIEW)

This installer UPDATES the existing Astur English installation IN PLACE.
It is an experimental fork, NOT an official stable upstream release.

BEFORE INSTALLING
- Quit Astur VI Preview if it is running. Never run both managers together.
- The original Astur installation will be replaced (same installer AppId
  and installation directory), but your user settings and workspaces are kept.
- Close Astur when the setup asks. The installer will offer to launch Astur
  at the end; this is optional.

ROLLBACK
The installer backs up the existing Astur.exe, astur-settings.exe,
astur.conf and navbar.conf (when present) to:
%LOCALAPPDATA%\Astur\UpgradeBackup\before-vi-update-2.4.0.1
A SECOND backup of the version currently installed is saved to:
%LOCALAPPDATA%\Astur\UpgradeBackup\before-vi-update-2.4.0.13
Both snapshots are kept on a repeat update. Do not remove either backup.
To roll back, first quit Astur and restore the saved binaries/configuration
from the second backup or reinstall the previously used installer.
Do not run the original and fork simultaneously.

WHAT IS NEW IN 2.4.0.13
- New "Protect active desktop from background tools" option is ON by default.
  A newly shown background window is not adopted into Astur's tiling layout
  until Windows actually foregrounds it. This prevents short-lived agent/CLI
  PowerShell/CMD scan consoles from stealing a tile or reshuffling the desktop.
- Windows' normal foreground-stealing guard remains enabled while this
  protection is active, including after live config reloads. User-selected
  terminals still become normal Astur-managed windows.
- Native title-bar drag can move a managed tiled window to another monitor,
  without holding Left Alt. Alt+drag and existing keyboard moves remain.
- A verified Zalo.exe TOPMOST, borderless, no-APPWINDOW notification host
  is ignored by Astur's tiling/adoption/focus rules. The normal chat window
  remains tileable. No Zalo window style or mouse capture is changed.
- Native maximize and mouse-hook guard changes from earlier 2.4.0.11.
WARNING: Actual NCPC/Zalo live behavior is not yet verified. If the popup
still blocks input, quit Astur and compare behavior with Astur not running.
Optional Windows & rules checkbox keeps native maximize/F11 windows and
borderless photo/video popups outside Astur's tile/tab layout. The rest of
the tiled windows keep normal per-window Windows focus and z-order.
Compact EN/VI language dropdown is now in the top-right toolbar.
Vietnamese Settings is the default for users without a locale preference.
The 821-entry catalog now covers all 14 Settings pages and more dynamic help,
validation, launcher and native menu text; English remains selectable.
Source-level coverage is not proof of every on-screen string.
Very shallow notifications anchored to the top/bottom screen edge are kept
out of Astur's tiling/tab registry without muting or hiding them.
The real Zalo/other messenger notification case still requires live E2E.
