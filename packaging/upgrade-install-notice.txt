ASTUR VI UPDATE 2.4.0.19 (EXPERIMENTAL PREVIEW)

This is an UNSIGNED experimental Windows x64 in-place Astur update.
Calculator and selected compact utilities open as their original Windows
free-sized windows, not maximized Astur CS slots.

IMPORTANT
- Quit running Astur before installing. Do not run two window managers.
- Test this preview with disposable apps outside any active MT5/SignalOps
  trading desktop. Actual Windows multi-monitor acceptance remains pending.
- Installer reuses Astur's original AppId and installed path; it does not
  automatically install, restart, or close other apps from GitHub.
- Do not disable Windows Defender or SmartScreen to bypass security warnings.
- User settings and workspace state are preserved; verify SHA256SUMS.txt.

ROLLBACK
Immediately previous installed binaries and available config are backed up to
%LOCALAPPDATA%\Astur\UpgradeBackup\before-vi-update-2.4.0.19
The original first-upgrade backup is retained at
%LOCALAPPDATA%\Astur\UpgradeBackup\before-vi-update-2.4.0.1
The backup is not overwritten on repeat installation. Exit Astur, restore
the saved files, or reinstall GitHub preview 2.4.0.18 if needed.

WHAT CHANGED IN 2.4.0.19
Astur now leaves these small utilities entirely to Windows by default:
- Calculator: calc.exe, Calculator.exe, CalculatorApp.exe,
  WindowsCalculator.exe; includes legacy UWP ApplicationFrameHost exact
  Calculator frame title fallback.
- Snipping Tool, Snip & Sketch, ScreenClippingHost.
- Character Map, Magnifier, On-Screen Keyboard, Task Manager, About Windows,
  Disk Cleanup, System Configuration, DirectX Diagnostic Tool.
- Sticky Notes, Clock/Alarms, Sound Recorder.

Unlike Astur FLOAT, IGNORE does not alter their window size, position,
z-order, focus presentation, CS1–CS4 slots, or scrolling workspace.
Existing explicit user app rules still take precedence, so you may choose
to tile or float-manage a specific utility if you prefer.
Chrome, Explorer, Notepad, Paint, Telegram, MT5 and terminal windows retain
their normal Astur tiling rules. Notifications, owned dialogs and native
fullscreen windows keep their original safety exclusions.

SOURCE TESTS VS REAL DESKTOP
Windows CI tests the new policy (known utility names, standard apps unaffected,
rule precedence, modal behavior), Rust tests and the installer/rollback smoke.
This does not prove every app/version/window class on a real desktop.
See docs/vi/SMALL_UTILITIES_NATIVE_UNMANAGED_20261106.md.
